# Research report assets

`optimizing-developer-experience-2026.pdf` is the unmodified September 2026 report supplied for publication, authored by Ibrahim Haddad with a foreword by Arun Gupta and published by The Linux Foundation with the Developer Relations Foundation.

`optimizing-developer-experience-2026.webp` is a rendering of its complete cover for the resource listing and report page.

Both assets retain the report's copyright and license: Copyright © 2026 The Linux Foundation, Creative Commons Attribution-NoDerivatives 4.0 International (CC BY-ND 4.0): https://creativecommons.org/licenses/by-nd/4.0/. These assets are not covered by the repository's default CC BY 4.0 license.

The website uses the cover title, *Optimizing Developer Experience for High Engineering Performance*. The supplied PDF's back-page citation instead uses *Optimizing Developer Experience for Enterprise Outcomes*. The original PDF has not been edited to reconcile these titles.
